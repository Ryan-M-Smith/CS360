# CS360 — Programming Languages

Coursework for **CS-360: Programming Languages** at Juniata College.

This repo covers a broad tour of languages, paradigms, and compiler concepts — from C++ and
Java to Lisp, Smalltalk, and custom lexical and syntax analysis.
